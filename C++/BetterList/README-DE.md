# BetterList Dokumentation
  Dieses README dient als Dokumentation dafür, wie BetterList funktioniert. Es enthält eine Beispiel-Eingabe, damit du verstehst, wie man durch das Menü navigiert. Es gibt keine vorherigen Versionen, da dies ein sehr altes Projekt ist, das ich Anfang 2025 gemacht habe.

## Tutorial
   ______________________
  |      To Do List      |
----------------------------
|1 Create Task.            |
|2 Edit Task               |
|3 Delete Task             |
|4 Display Tasks           |
|5 Complete Task           |
|6 Exit                    |
----------------------------

  „1“ fordert dich auf, einen Namen, eine Beschreibung und ein Fälligkeitsdatum für deine Aufgabe einzugeben.
  „2“ listet alle Aufgaben auf und erlaubt dir, eine zum Bearbeiten auszuwählen.
  „3“ listet alle Aufgaben auf und erlaubt dir, eine dauerhaft zu löschen. Das ist nicht rückgängig.
  „4“ zeigt alle gespeicherten Aufgaben an und ob sie erledigt sind oder nicht.
  „5“ listet alle Aufgaben auf und erlaubt dir, eine als erledigt zu markieren.
  „6“ schließt das Programm.

  Beispiel-Eingabe:
  1
  Wash the dishes
  Wash the dishes by 5 P.M or else mom will be mad!
  17.02.26

  Beispiel-Ausgabe:
  Task added!
