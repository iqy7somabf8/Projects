# BetterList Documentation
  This README serves to show some documentation as to how the BetterList works. It contains a sample input so you can understand how to properly navigate the menu. No previous versions are available, as this is a really old project I did in early 2025.

## Tutorial

----------------------------
|1 Create Task.            |
|2 Edit Task               |
|3 Delete Task             |
|4 Display Tasks           |
|5 Complete Task           |
|6 Exit                    |
----------------------------

"1" Will prompt you to enter in a name, description and due date for your Task.

"2" Will list out all tasks and allow you to pick one to edit.

"3" Will list out all tasks and allow you to pick one to remove forever (irreversible).

"4" Lists out all saved tasks and wether or not they're completed.

"5" Will list out all tasks and allow you to pick one to mark as completed.

"6" Closes The program.

Sample input:

1

Wash the dishes

Wash the dishes by 5 P.M or else mom will be mad!

17.02.26

Sample output:

Task added!
